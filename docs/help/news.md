## What this page is for

A live, de-duplicated feed of security news and advisories from CISA, BleepingComputer, The Hacker News,
vendor threat-intel blogs and others. CVE IDs mentioned in articles link back to CVE Intelligence.

## How to use it

This module ships in **Phase 5**.

<!-- requires: news:manage -->
Admins will manage feeds under **Settings → News feeds**.
<!-- /requires -->
