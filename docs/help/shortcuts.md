summary: Keyboard shortcuts available throughout the app.
keywords: [keyboard, shortcuts, accessibility]
docs: help/shortcuts/
---

| Keys | Action |
|---|---|
| `?` | Open help for the current page |
| `/` | Focus the search box (CVE Intelligence) |
| `Esc` | Close the help drawer, tooltip or dialog |
| `g` then `c` | Go to CVE Intelligence |
| `g` then `h` | Go to Help Center |
| `Tab` / `Shift+Tab` | Move between controls. Every action is reachable by keyboard |
